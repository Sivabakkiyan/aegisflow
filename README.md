# AegisFlow


AegisFlow is a financial crime detection and investigation platform designed to help detect suspicious payment transactions and support Anti-Money Laundering (AML) investigations.

The project has two main parts.

First, AegisFlow analyzes transactions in real time and gives each transaction a fraud/risk score. It uses machine learning along with transaction behavior, transaction velocity, and connections between accounts, devices, IPs, and merchants. The system also provides reasons for why a transaction was considered risky.

Second, when suspicious activity is detected, AegisFlow creates an investigation case. An AI-based investigation system helps analyze transaction patterns, connected entities, and relevant information, and then prepares an evidence-based Suspicious Activity Report (SAR) draft.

The final decision is always kept with a human compliance analyst. The AI helps with investigation and report preparation, but it does not independently file a report.

## Main Goals

- Detect suspicious transactions in real time
- Reduce unnecessary false alerts
- Explain why a transaction is considered risky
- Identify connections between suspicious accounts and entities
- Help analysts investigate AML cases faster
- Generate evidence-based SAR drafts
- Keep humans involved in the final approval process
